# OpenFloat Operator Dashboard

The official frontend web interface for the OpenFloat Enterprise Middleware Portal. This React application provides system operators and administrators with a centralized dashboard to manage user access, process STK Pushes, handle payouts, and configure active Safaricom Daraja API Paybills.

## Technology Stack

* **Framework:** React 18
* **Build Tool:** Vite
* **Styling:** Tailwind CSS
* **Backend Integration:** Communicates with the OpenFloat Spring Boot / PostgreSQL middleware via REST APIs.
